RESTIVO FRONTEND
================

This package contains the completed Restivo frontend with the original marketing landing page and the live restaurant menu preview.

EXACT STATIC WEBSITE
--------------------
The ready-to-serve static website is in:
  source/artifacts/restivo-landing/dist/public/

Serve that dist/public folder with any static web server. Do not open index.html directly if your browser blocks local assets.

EDITABLE SOURCE
---------------
The editable Vite/React source is in:
  source/artifacts/restivo-landing/

The source package is preserved in its original workspace layout, with the required image assets in:
  source/attached_assets/generated_images/

FEATURES
--------
- Restivo marketing landing page
- Arabic-first RTL layout with English toggle
- Live restaurant preview opened by the Try live restaurant buttons
- Search, category filters, cart, quantity controls, share, and WhatsApp order action
- Responsive mobile and desktop layouts
